# Languages and release boundaries

[English](../README.md) · [Русский](../README.ru.md) · [Українська](../README.uk.md) · [Deutsch](../README.de.md) · [Français](../README.fr.md) · [Nederlands](../README.nl.md)

These six README files are maintained documentation translations. Shared Vue application localization is developed and released in [inverter-dashboard-vue](https://github.com/victron-venus/inverter-dashboard-vue), then adopted by each backend as verified assets. Documentation language availability is not evidence that a particular installed UI already has those catalogs or a language selector.

The adopted official Vue `v2.2.9` artifact supports English, Russian, Ukrainian, German, French and Dutch. [static/source-info.json](../src/inverter_dashboard/static/source-info.json) records source `f86943ebc764688c32bc4389f2276bc12682a90e`, the accepted RC `v2.2.9-rc.2` (build run `39039690585`) and the exact file inventory. Interface labels, date/time formatting, retained application errors and theme labels use the selected language; provider-supplied messages retain their original text. Inspect that manifest and the actual served build when testing an installed version. An older installation does not acquire these translations merely by reading updated documentation.

## Translation conventions

- Keep API names, environment variables, MQTT paths, request IDs and source-defined enum values unchanged.
- Translate user-facing labels and explanatory sentences as complete messages; do not assemble grammar by concatenating fragments.
- Preserve the meaning of unknown/stale/partial/read-only. Never translate an unavailable reading into zero or an accepted command into physical success.
- Localize number/date presentation without changing underlying units or original timestamps. Show the timezone for exact event times; relative age still derives from the source occurrence.
- Device names, HA friendly names, controller descriptions and source alarm text may arrive in another language. Do not claim they are catalog translations or alter their diagnostic meaning.
- Treat persisted language preferences separately from private connection credentials and controller tariff plans. The current Python settings API accepts only its declared keys; do not add an arbitrary `language` key before an explicit backend contract supports it.

When updating behavior, update the English guide and all five README translations together. Check linked guides and commands after translation. Security warnings, restart requirements, unsupported server platforms and preview release limitations are part of the translated content, not optional footnotes.
