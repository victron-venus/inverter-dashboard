# Inverter Dashboard · Python

[English](README.md) · [Русский](README.ru.md) · [Українська](README.uk.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Nederlands](README.nl.md)

Вебпанель для самостійного розміщення й моніторингу систем Victron. Сервер Python/FastAPI отримує нативні дані Cerbo GX через MQTT або HTTPS [inverter-gateway](https://github.com/victron-venus/inverter-gateway) (IGW) та обслуговує спільний інтерфейс Vue. Необов'язковий [inverter-control](https://github.com/victron-venus/inverter-control) надає політику керування, історію, прогнози й тарифи. Для нативної телеметрії він не потрібний. Home Assistant додає лише налаштовані вами пристрої.

Цей проєкт призначений для Python-сервера, контейнера або NAS. Є також [реалізація Go](https://github.com/victron-venus/inverter-dashboard-go) та [нативний застосунок](https://github.com/victron-venus/inverter-desktop); їхні пакети не взаємозамінні.

## Можливості

- Фази мережі й споживання, сонячна генерація DC/AC, батареї, заряджання EV, нативні навантаження, рівень води, насос і клапан. Відсутні дані не перетворюються на виміряний нуль.
- Попередження Victron із початковим часом події, включно з неактивними, але ще не підтвердженими попередженнями.
- Шість режимів ESS за підтримки контролера: Off, On, Optimized with battery life, Optimized without battery life, Keep batteries charged і External control.
- Команди з перевіркою можливостей і актуальності: прапорці контролера, Water Mode, постійний Setpoint Override і тариф із перевіркою ревізії. Прийнята транспортом команда ще не доводить фізичного виконання.
- Налаштовувані кнопки Home, штори, медіаплеєри, сцени, датчики й числові параметри. Особистого списку HA-сутностей у коді немає. Картки побутової техніки залежать від видимості та доступних/активних даних.
- Історія, прогнози й добова енергія з походженням та повнотою даних. Неповна доба не видається за повну; тарифні редактори винесені з верхнього підсумкового рядка.
- Добровільні системні Web Push сповіщення, постійні підписки, дедуплікація й тиха початкова синхронізація після перепідключення.

Вбудовано офіційний артефакт **Vue v2.2.9** (версія пакета `2.2.9`, вихідний код `f86943ebc764688c32bc4389f2276bc12682a90e`). [Дані про походження](src/inverter_dashboard/static/source-info.json) містять метадані й хеші файлів. Байти збігаються з перевіреною RC `v2.2.9-rc.2` (збірка `39039690585`). Тексти інтерфейсу, дати, час, збережені помилки застосунку й підписи тем підтримують англійську, російську, українську, німецьку, французьку та нідерландську мови; повідомлення зовнішніх джерел зберігають початковий текст. Докладніше — [підтримка мов](docs/i18n.md).

## Локальний запуск

Потрібні Python 3.12+ та `uv`. Репозиторій містить зафіксовані файли Vue; для звичайного запуску не треба перебудовувати інтерфейс.

```sh
git clone https://github.com/victron-venus/inverter-dashboard.git
cd inverter-dashboard
uv sync --locked
# Перший запуск лише на loopback, без підключення до обладнання.
GATEWAY_ENABLED=false uv run --locked inverter-dashboard --mqtt-host ""
```

Відкрийте `http://127.0.0.1:8080`. Без джерела живої телеметрії не буде. Перед віддаленим доступом задайте випадковий `DASHBOARD_SECRET` та HTTPS. Порожній секрет залишає керувальні API незахищеними; loopback не замінює автентифікацію.

Для MQTT задайте `MQTT_HOST`, `MQTT_PORT`, `CERBO_PORTAL_ID`, а за потреби — облікові дані й TLS із перевіркою сертифіката. Для IGW задайте `MQTT_HOST=""`, `GATEWAY_ENABLED=true`, `GATEWAY_URL=https://gateway.example.com` і `GATEWAY_API_TOKEN`. Обидва параметри Cloudflare Access потрібні лише для відповідного маршруту та мають задаватися разом. `.example.com` — вигаданий приклад.

Якщо налаштовано обидва транспорти, доступний MQTT має пріоритет, а IGW забезпечує резервне підключення. Щоб залишити лише IGW, очистіть MQTT-адресу. Для надійного запуску на мовчазному брокері задайте портал явно. IGW приймає HTTPS origin без префікса шляху чи перенаправлення. Збережені параметри застосовуються при запуску; явні `--mqtt-host`/`--mqtt-port` мають найвищий пріоритет. Докладніше: [конфігурація](docs/configuration.md).

## Контейнери й готові виконувані файли

Оберіть потрібний канал [офіційного випуску](https://github.com/victron-venus/inverter-dashboard/releases). ZIP для Linux x86_64, macOS arm64/x86_64 та Windows x86_64 містить Python і Vue. Перед розпакуванням перевірте SHA-256 за відповідним `.sha256`, потім запустіть `inverter-dashboard --help` або `inverter-dashboard.exe --help`. Beta/RC — попередні версії.

Для контейнера використовуйте перевірений digest образу, явно відкрийте порт і за потреби встановіть `HOST=0.0.0.0` усередині контейнера. [Compose](docker-compose.yml), [Portainer](portainer-stack.yml) та [k3s](deploy/k3s/README.md) потребують адаптації до вашої мережі. Процес працює з UID/GID 1000; надайте йому читання конфігурації та запис до окремого приватного сховища.

Задайте `INVERTER_DASHBOARD_SETTINGS_FILE=/var/lib/inverter-dashboard/settings/dashboard_settings.json` на постійному томі. Read-only `/app/config` не підходить для запису налаштувань. Web Push потребує окремого `WEB_PUSH_DATA_DIR=/var/lib/inverter-dashboard/notifications` на постійному локальному томі та одного процесу/репліки. Зберігайте ключ VAPID, підписки й дедуплікацію під час оновлення. Приватні дані не повинні потрапляти до каталогу статичних вебфайлів.

## Home Assistant і побутова техніка

Виконайте `bash scripts/init-config.sh`, відредагуйте ігнорований Git файл `local_config.py`. У контейнері його каталог задає `INVERTER_DASHBOARD_CONFIG`. Укажіть власні `HA_URL`/`HA_TOKEN` та ввімкніть `HA_DIRECT_CONTROLS=True` для прямої HA-інтеграції. Токен не можна публікувати.

`HA_SWITCH_ENTITIES` — словник, ключами якого є сталі назви кнопок Home. Значення кожного ключа — рядок ID сутності, пара `(entity, label)` або об'єкт із `entity`, `label`, `order`, `enabled`. Порожній словник (`{}`) означає відсутність кнопок. Вимкнені записи не відображаються, не опитуються та не дозволяють команд. HA-дзеркала не замінюють нативні Water/EV/потужність чи прапорці контролера. Інші картки задає `HA_FILTERED_ENTITIES`.

Для dishwasher/washer/dryer налаштуйте власні `HA_APPLIANCE_ENTITIES` та видимість. Наявність таймера не доводить роботу приладу; спільний лічильник розеток не є вимірюванням окремої пральної машини. [Посібник](docs/configuration.md#home-assistant) містить структури та обмеження.

## Сповіщення й безпека

Банер показує час події, а не повернення в домашню мережу. Невідомий час залишається невідомим. Локальне приховування та підтвердження на пристрої — різні дії. Для Web Push увімкніть `WEB_PUSH_ENABLED=true`, постійне сховище й дозвіл браузера. Кнопка тесту підтверджує чергу, а не відображення ОС.

Серверний відправник підтримується на Linux і macOS Apple Silicon; на Windows та Intel macOS панель працює, але відправник повертає `unsupported_platform`. Браузери цих платформ можуть отримувати push від Linux-сервера. Умови браузера, строк події й тихий reconnect описані в [посібнику сповіщень](docs/notifications.md).

Команди потребують актуального джерела та свіжих даних. Після зміни підключення старі callbacks і команди втрачають повноваження. Не обходьте заблоковані кнопки й не повторюйте непевну фізичну команду навмання. Setpoint Override навмисно незалежний від DRY і працює в контролері до явної зупинки. Тариф перевіряє ревізію, щоб не перезаписати паралельну зміну.

TLS перевіряє сертифікат та ім'я сервера. Для приватного CA налаштуйте довіру, а не вимикайте перевірку. Токен у URL може потрапити до історії чи proxy-логів; API-клієнтам краще передавати Authorization. Див. [TLS](docs/tls-policy.md) та [Security](SECURITY.md).

## Діагностика й розробка

`/health/live` перевіряє процес, а не свіже обладнання. `/api/state` без авторизації повертає підключення; живі поля потребують авторизації, якщо встановлено секрет. Перевіряйте транспорт, портал, права брокера й можливості пристрою. Заблокована кнопка може означати застарілі дані або відсутню пряму HA-сесію. При помилці збереження перевірте шлях, права й місце; тимчасовий том не переживе заміну pod.

Для старого інтерфейсу порівняйте фактичний build з обраним випуском, не видаляючи підписки чи серверні ключі навмання.
